# HTML Resume

This repository contains a simple HTML-based resume project. It demonstrates the use of various HTML tags and includes a theme toggle feature implemented with JavaScript.

## File Structure

- `index.html`: The main HTML file containing the resume content.
- `scripts/theme-toggle.js`: JavaScript file for toggling between light and dark themes.

## Explanation of HTML Tags Used

Below is a list of HTML tags used in `index.html` and their purposes:

- `<html>`: The root element of the HTML document.
- `<head>`: Contains metadata, links to stylesheets, and the page title.
- `<title>`: Sets the title of the web page (shown in the browser tab).
- `<meta>`: Provides metadata such as character encoding and viewport settings.
- `<link>`: Links external resources like CSS files.
- `<body>`: Contains the visible content of the web page.
- `<header>`: Defines the header section, often containing the name and contact info.
- `<nav>`: Contains navigation links to different sections of the resume.
- `<main>`: The main content area, including sections like education, experience, and skills.
- `<section>`: Groups related content together (e.g., Education, Experience).
- `<h1>`, `<h2>`, `<h3>`: Headings of various levels for section titles and subsections.
- `<p>`: Paragraphs of text.
- `<ul>`, `<ol>`: Unordered and ordered lists for listing items such as skills or job duties.
- `<li>`: List items within `<ul>` or `<ol>`.
- `<a>`: Hyperlinks to email, phone, or external sites.
- `<img>`: Displays images, such as a profile picture (if included).
- `<footer>`: Footer section, often containing copyright or contact info.
- `<button>`: Used for interactive elements like the theme toggle.
- `<script>`: Links to JavaScript files (e.g., for theme toggling).

## Theme Toggle Feature

This project includes a theme toggle feature that allows users to switch between light and dark modes. The functionality is implemented in `scripts/theme-toggle.js` and can be triggered by clicking the theme toggle button on the page.
