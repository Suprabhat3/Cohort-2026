
# Mintlify Marketing Site Clone

>A pixel-perfect, desktop-focused clone of the Mintlify marketing site, built with **vanilla HTML and CSS**. No frameworks, no build tools, just pure frontend craftsmanship.

---

## 🚀 Demo

[Live Site](https://mintlify-clone-css.vercel.app/)

---

## 📝 Features

- **Pixel-faithful design**: Closely matches the original Mintlify marketing site.
- **Pure HTML & CSS**: No JavaScript, frameworks, or dependencies.
- **Hero & Navigation**: Includes navigation bar, hero section, and background SVGs.
- **Feature Sections**: Desktop-first layout with inline SVGs, video/image placeholders, and CTA grids.
- **Customers & CTA**: Customer stories, call-to-action blocks, and multi-column footer.
- **Accessible & Semantic**: Uses semantic HTML and accessible markup where possible.
- **Easy to customize**: Swap out assets or text as needed.

## 🛠 Getting Started

1. **Clone this repository:**
	```sh
	git clone <repo-url>
	```
2. **Open the project folder:**
	- Navigate to `mintlify-clone/`.
3. **Launch the site:**
	- Open `index.html` directly in your browser.
4. **Customize:**
	- Replace placeholder assets (videos, images) in the `ascets/` folder as needed.
	- Edit text or links in `index.html` for your use case.
