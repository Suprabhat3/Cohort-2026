Mintlify Clone – Web Dev Cohort 2026
====================================

Overview
--------
This project is a pixel-faithful clone of the Mintlify marketing site built with plain HTML and CSS. It recreates the hero, navigation, feature sections, assistant/video placeholders, CTA blocks, and footer without any frameworks or build tooling.

What’s inside
-------------
- **Pure frontend**: Vanilla HTML and CSS only—no JS or dependencies.
- **Hero + nav**: Uses `ascets/bg-light.svg` for the shared background and `ascets/hero-image-light.svg` for the main mockup.
- **Feature sections**: Multiple desktop-first sections with inline SVG icons, video placeholders, and CTA grids.
- **Footer**: Multi-column footer with social links and status pill to mirror the reference design.
